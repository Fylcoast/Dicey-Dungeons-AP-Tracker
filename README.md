# Dicey-Dungeons-AP-Tracker
PopTracker package for playing Dicey Dungeons with Archipelago

Only autotracking with Archipelago is currently supported. Most features work manually, but not all (like received equipment counts).

Features:
- All items and locations as of Dicey Dungeons AP version 0.4.2
- Aggregate items to show amount of equipment available in each episode
- Location visibility which follows logic
